BLOCKPOJAV — Android UI prototype

Это прототип интерфейса лаунчера, не готовый игровой лаунчер.
Есть: тёмный экран, выбор версии (примерный список + ручной ввод), поле офлайн-профиля, кнопка Microsoft (пока заглушка), визуальная настройка RAM.

Пока НЕТ: Minecraft Java runtime, автоматической загрузки Java/игровых библиотек, авторизации Microsoft OAuth, загрузчика версий, рендерера и запуска игры. Кнопка ИГРАТЬ честно сообщает об этом.

Офлайн-профиль — только локальное имя для интерфейса. Он не даёт лицензию и не обходит проверку владения игрой. Для официального Microsoft-входа потребуется безопасная OAuth-интеграция и лицензия Minecraft Java. После первоначальной авторизации некоторые легальные сборки могут поддерживать офлайн-режим без сети в пределах своих правил.

Сборка APK через GitHub Actions:
1. Распакуйте ZIP.
2. Загрузите СОДЕРЖИМОЕ папки BlockPojav_Android в корень GitHub-репозитория (не ZIP).
3. Убедитесь, что в корне видны app/, .github/, build.gradle, settings.gradle.
4. Откройте Actions → Build BlockPojav APK → Run workflow.
5. После зелёной галочки скачайте Artifact BlockPojav-debug-apk. Внутри app-debug.apk.
