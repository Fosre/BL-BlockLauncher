BLOCKPOJAV BETA — СБОРКА С РЕАЛЬНЫМ ИГРОВЫМ ЯДРОМ

Эта сборка заменяет прежний экран-прототип полноценным Android-лаунчером на базе Zalith Launcher 2. В главном окне будет видна надпись «BlockPojav БЕТА • НЕОФИЦИАЛЬНАЯ МОДИФИКАЦИЯ», а иконка заменена на BlockPojav.

Ядро предоставляет официальный каталог версий, установку и запуск Minecraft Java, Android Java runtime и графические backend-ы, Microsoft-вход и редактор сенсорного управления. Для игры по сети нужен Microsoft-аккаунт с правом владения Minecraft Java Edition. Офлайн-профиль не обходит проверку лицензии и используется только в рамках правил игры.

ВАЖНО ПРО ПРОЕКТ И ЛИЦЕНЗИЮ
- Код Zalith Launcher 2 распространяется по GPL-3.0. Условия требуют изменить название модификации и ясно пометить её как неофициальную; в этом варианте оба требования выполнены.
- Корневой репозиторий содержит скрипт изменений и точный commit исходного проекта. GitHub Actions собирает соответствующий APK и отдельный ZIP с полным изменённым исходным кодом и лицензией GPL-3.0.
- Вместо прежнего простого экрана появится полноценный лаунчер с собственными меню версий, аккаунтов, памяти и управления. Старый статический экран не используется в новой APK.
- APK собирается для ARM64. 32-битным телефонам потребуется отдельная сборка.
- Старые ключи подписи Zalith удаляются. Debug APK подписывается временным ключом GitHub Actions. При каждом новом Actions запуске подпись меняется, поэтому для установки очередного APK нужно удалить предыдущую beta-сборку.

КАК ОБНОВИТЬ РЕПОЗИТОРИЙ GITHUB
1. Распакуй BlockPojav_Beta_Pipeline.zip.
2. Загрузи папку .github и папку scripts в корень Fosre/BL-BlockLauncher, заменив старый .github/workflows/android.yml.
3. Добавь README_RU_BETA.txt в корень репозитория.
4. Открой Actions → Build BlockPojav Beta → Run workflow.
5. После успешной сборки скачай BlockPojav-Beta-arm64-apk, распакуй его и установи APK на Android.
6. Если понадобится исходный код той же сборки, скачай BlockPojav-Beta-source-GPL-3.0 из Actions Artifacts.

ПЕРВЫЙ ЗАПУСК
1. Открой лаунчер и добавь Microsoft-аккаунт, которому принадлежит Minecraft Java Edition.
2. В каталоге выбери официальную версию Minecraft и установи её.
3. В редакторе управления настрой кнопки на экране. Видео с четырьмя вариантами, которое ты прислал, сейчас недоступно для просмотра; исходник содержит обновлённый редактор управления, но точные старые раскладки из ролика здесь не воспроизводятся.
4. Открой установленную версию и нажми Play.
